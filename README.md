# The Sims 4 mod loader

The script extender of The Sims 4: the DLL that the game loads. It is a port of the logic of the Masters of Albion
mod loader to this game. It owns every hook, loads and checks the DLL mods, gives the Dear ImGui menu bar on the
swap chain of the game, the settings file, hotkeys, main-thread tasks and inspector queries, and a native Python
module for script mods.

The port is in progress. See `docs/port.md` for the parts and their state.
